# BetAnalytic – δυναμική αγορά συνολικών γκολ

Η έκδοση αυτή δεν αλλάζει την εκπαίδευση ή τα βάρη του υπάρχοντος ensemble.
Προσθέτει μόνο αναλυτικότερη εξαγωγή αγορών γκολ από την ήδη υπολογισμένη
κατανομή σκορ.

## Τι προστέθηκε

Για κάθε πρόβλεψη υπολογίζονται πλέον οι γραμμές:

- Over/Under 0.5
- Over/Under 1.5
- Over/Under 2.5
- Over/Under 3.5
- Over/Under 4.5
- Over/Under 5.5

Το feed περιέχει νέο πεδίο:

```json
"total_goals_market": {
  "selected": {
    "side": "UNDER",
    "line": 3.5,
    "label": "Under 3.5",
    "probability": 0.7556,
    "probability_percent": 75.56
  },
  "all_lines": []
}
```

Η επιλογή γίνεται ως εξής:

1. Κρατούνται μόνο οι γραμμές που βρίσκονται έως 1 γκολ μακριά από τα
   αναμενόμενα συνολικά γκολ του συγκεκριμένου αγώνα.
2. Για κάθε σχετική γραμμή επιλέγεται η πιθανότερη πλευρά, Over ή Under.
3. Από αυτές εμφανίζεται η επιλογή με τη μεγαλύτερη πιθανότητα.

Έτσι δεν επιλέγεται μία άχρηστη ακραία γραμμή, όπως Under 5.5 σε αγώνα με
αναμενόμενα 2.2 γκολ, μόνο και μόνο επειδή έχει πολύ μεγάλη πιθανότητα.

## Συμβατότητα

Τα παλιά πεδία `over_2_5`, `under_2_5` και BTTS παραμένουν ακριβώς όπως ήταν.
Η παλιά Android εφαρμογή συνεχίζει να λειτουργεί. Για να εμφανιστεί η νέα
δυναμική αγορά, θα χρειαστεί στο επόμενο στάδιο μικρή αλλαγή στην Android
εφαρμογή ώστε να διαβάζει το `total_goals_market.selected`.

## Κόρνερ και κάρτες

Η τρέχουσα έκδοση παράγει δυναμικές αγορές κόρνερ και κίτρινων καρτών από
τα διαθέσιμα Football-Data CSV και το αποθηκευμένο ιστορικό API-Football.
Αν δεν υπάρχει επαρκές ιστορικό για μία ομάδα, μόνο η συγκεκριμένη αγορά
επιστρέφει `unavailable`· η πρόβλεψη γκολ/αποτελέσματος παραμένει διαθέσιμη.
