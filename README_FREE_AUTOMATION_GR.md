# BetAnalytic — δωρεάν αυτόματη έκδοση με διασταύρωση

Η έκδοση αυτή:

- δεν κάνει scraping στο `slgr.gr`,
- δεν χρειάζεται πληρωμένο API,
- λειτουργεί χωρίς κανένα API key,
- μπορεί προαιρετικά να χρησιμοποιήσει το δωρεάν API-Football plan μόνο ως επιπλέον έλεγχο,
- δεν εμφανίζει μη επιβεβαιωμένη ώρα σαν βέβαιη.

## Πηγές που χρησιμοποιούνται

1. **Fixtur.es calendar feed** — πρόγραμμα και αλλαγές ώρας/ημερομηνίας.
2. **OpenFootball CC0/public domain** — ανεξάρτητη διασταύρωση προγράμματος και αποτελεσμάτων όταν έχει δημοσιευτεί η σεζόν.
3. **Football-Data.co.uk CSV** — ιστορικά αποτελέσματα, κόρνερ, κάρτες και άλλα διαθέσιμα στατιστικά.
4. **API-Football Free (προαιρετικό)** — μόνο για δεύτερη επιβεβαίωση του τρέχοντος προγράμματος. Δεν γίνεται ποτέ μοναδική πηγή αλήθειας.

## Κανόνας ημερομηνίας και ώρας

Η ώρα παίρνει:

```json
"kickoff_time_confirmed": true
```

μόνο όταν τουλάχιστον δύο δωρεάν πηγές:

- αναγνωρίζουν τον ίδιο αγώνα,
- συμφωνούν στην ημερομηνία Ελλάδας,
- και οι ώρες τους απέχουν έως 30 λεπτά.

Αν υπάρχει μόνο μία πηγή ή διαφωνία, το feed κρατά τον αγώνα αλλά ορίζει:

```json
"kickoff_time_confirmed": false
```

Η Android εφαρμογή πρέπει τότε να εμφανίζει **«Ώρα προς επιβεβαίωση»** και όχι την τεχνική ώρα του JSON.

## Πλήρης αυτοματοποίηση

### `Update and publish BetAnalytic data`

Τρέχει ανά δύο ώρες και:

1. κατεβάζει ξανά το πρόγραμμα από τις διαθέσιμες δωρεάν πηγές,
2. διασταυρώνει ομάδες, ημερομηνίες και ώρες,
3. κρύβει τις αμφίβολες ώρες,
4. ενημερώνει τη SQLite με νέους ολοκληρωμένους αγώνες,
5. ενημερώνει κόρνερ και κάρτες όταν δημοσιευτούν στα CSV,
6. επανυπολογίζει τις προβλέψεις με αυστηρό χρονικό cutoff,
7. δημιουργεί νέο `feed.json`,
8. το δημοσιεύει στο GitHub Pages.

### `Sync free match history`

Τρέχει καθημερινά και αποθηκεύει μόνιμα:

- `betanalytic.db`,
- `data/fixture_statistics.json`,
- `data/free_history_sync_summary.json`.

Έτσι τα περσινά κενά που συμπληρώνονται από τη δωρεάν πηγή και τα νέα ολοκληρωμένα παιχνίδια μπαίνουν αυτόματα στον αλγόριθμο.

## Ρυθμίσεις GitHub

### Χωρίς key

Δεν απαιτείται κανένα Secret. Η εφαρμογή λειτουργεί με τις τρεις πηγές χωρίς κλειδί.

### Προαιρετική δωρεάν επιβεβαίωση API-Football

Το επίσημο δωρεάν plan είναι $0 και δίνει 100 requests την ημέρα. Για καλύτερη και ταχύτερη διασταύρωση του νέου προγράμματος:

1. Δημιούργησε δωρεάν λογαριασμό στο API-Football.
2. Στο GitHub άνοιξε:
   `Settings → Secrets and variables → Actions → Secrets`.
3. Πρόσθεσε:

```text
Name: API_FOOTBALL_KEY
Value: το δωρεάν key σου
```

Το workflow κάνει έως δύο fixture requests ανά εκτέλεση. Με εκτέλεση ανά δύο ώρες παραμένει αρκετά κάτω από το δωρεάν ημερήσιο όριο.

Το API-Football χρησιμοποιείται **μόνο ως διασταύρωση**. Αν διαφωνεί με άλλη πηγή, η ώρα κρύβεται.

### Προαιρετική μεταβλητή

```text
BETANALYTIC_LOOKAHEAD_DAYS=45
```

## Πρώτη εκτέλεση

1. Αντικατάστησε όλα τα αρχεία του repository με αυτά του ZIP.
2. Κάνε commit στο `main`.
3. Προαιρετικά πρόσθεσε το δωρεάν `API_FOOTBALL_KEY`.
4. Άνοιξε `Actions → Sync free match history → Run workflow`.
5. Μετά άνοιξε `Actions → Update and publish BetAnalytic data` και έλεγξε ότι έγινε πράσινο.
6. Έλεγξε το νέο `feed.json`.

## Ενδείξεις ποιότητας στο `schedule_source`

- `verified date and time`: ημερομηνία και ώρα συμφωνούν σε δύο ή περισσότερες πηγές,
- `verified date; time pending`: συμφωνεί η ημερομηνία αλλά όχι η ώρα,
- `source conflict; time hidden`: οι πηγές διαφωνούν,
- `single source; time pending`: υπάρχει μόνο μία διαθέσιμη πηγή.

## Σημαντικοί περιορισμοί

- Το OpenFootball είναι ρητά CC0/public domain, αλλά μπορεί να καθυστερήσει να ανεβάσει τη νέα σεζόν.
- Το Football-Data ενημερώνει τα αρχεία περιοδικά, όχι ζωντανά μετά τη λήξη κάθε αγώνα.
- Η Fixtur.es δηλώνει ότι το δωρεάν calendar feed ενημερώνεται αυτόματα, αλλά δεν βρέθηκε στην ιστοσελίδα της εξίσου σαφής CC0 άδεια αναδημοσίευσης για app-store εφαρμογή.
- Το Football-Data διαθέτει δωρεάν CSV για ανάλυση, αλλά αναφέρει «All Rights Reserved» και δεν βρέθηκε σαφής CC0 άδεια αναδημοσίευσης.
- Για δημόσια εμπορική κυκλοφορία εφαρμογής, έλεγξε τους όρους κάθε πηγής ή χρησιμοποίησε πάροχο με ρητή άδεια διανομής. Αυτό δεν αποτελεί νομική γνωμοδότηση.

Δες επίσης το `SOURCE_LICENSES_AND_LIMITS_GR.md`.
