# BetAnalytic — Κόρνερ και κάρτες, Στάδιο 1

Αυτό το στάδιο **δεν εμφανίζει ακόμη προβλέψεις** στην εφαρμογή. Συλλέγει και
αποθηκεύει πραγματικά ιστορικά δεδομένα, ώστε το επόμενο στάδιο να κάνει
walk-forward backtest πριν δημοσιευθούν αγορές.

## Τι συλλέγεται

Για κάθε ολοκληρωμένο παιχνίδι:

- κόρνερ γηπεδούχου και φιλοξενούμενης,
- κίτρινες κάρτες γηπεδούχου και φιλοξενούμενης,
- κόκκινες κάρτες, όταν η πηγή τις παρέχει.

Οι προβλέψεις καρτών θα βασιστούν στις **κίτρινες κάρτες**. Οι κόκκινες
κρατιούνται χωριστά, επειδή οι κανόνες υπολογισμού διαφέρουν ανά αγορά και
στοιχηματική.

## Γιατί αποθηκεύονται σε JSON

Το GitHub Actions τρέχει σε προσωρινό υπολογιστή. Το αρχείο
`data/fixture_statistics.json` γίνεται commit στο repository και συνεπώς τα
δεδομένα δεν χάνονται στην επόμενη εκτέλεση.

## Εκτέλεση

1. Το secret `API_FOOTBALL_KEY` πρέπει να υπάρχει στο GitHub.
2. Άνοιξε `Actions`.
3. Επίλεξε `Collect corners and cards history`.
4. Πάτησε `Run workflow` με:
   - seasons: `2022,2023,2024`
   - max_requests: `90`
5. Μετά το πράσινο run, άνοιξε:
   `data/statistics_collection_summary.json`.

Ο collector ζητά έως 20 fixture IDs ανά API request και παραλείπει αγώνες που
έχουν ήδη αποθηκευτεί. Επομένως μια δεύτερη εκτέλεση δεν ξανακατεβάζει όλο το
ιστορικό.

## Επόμενο στάδιο

Μετά τη συλλογή θα προστεθούν:

- walk-forward backtest μοντέλου κόρνερ,
- walk-forward backtest μοντέλου κίτρινων καρτών,
- δυναμικές γραμμές ανά αγώνα,
- επιλογή της πιθανότερης ρεαλιστικής γραμμής,
- νέα πεδία στο `feed.json`,
- εμφάνιση στην Android εφαρμογή.
