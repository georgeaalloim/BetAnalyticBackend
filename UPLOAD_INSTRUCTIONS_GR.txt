BETANALYTIC — ΑΝΕΒΑΣΜΑ ΝΕΑΣ ΔΩΡΕΑΝ ΕΚΔΟΣΗΣ

1. Κράτησε αντίγραφο ασφαλείας του υπάρχοντος repository.
2. Διέγραψε τα παλιά αρχεία από το root, εκτός αν θέλεις να κρατήσεις Git history.
3. Ανέβασε ΟΛΑ τα περιεχόμενα του BetAnalyticBackend-FREE-crosschecked.zip.
4. Κάνε commit στο branch main.
5. GitHub → Settings → Pages → Source: GitHub Actions.
6. Προαιρετικά:
   Settings → Secrets and variables → Actions → New repository secret
   Name: API_FOOTBALL_KEY
   Value: δωρεάν API-Football key
7. Actions → Sync free match history → Run workflow.
8. Actions → Update and publish BetAnalytic data → Run workflow.
9. Έλεγξε το feed.json και τις ενδείξεις kickoff_time_confirmed.

Δεν χρειάζεται καμία πληρωμένη συνδρομή.
