# Διόρθωση συλλογής κόρνερ και καρτών για Free plan

Η προηγούμενη έκδοση χρησιμοποιούσε:

```text
/fixtures?ids=ID1-ID2-...
```

Το συγκεκριμένο ομαδικό parameter απορρίφθηκε από το Free plan. Η νέα
έκδοση χρησιμοποιεί το κανονικό endpoint στατιστικών:

```text
/fixtures/statistics?fixture=FIXTURE_ID
```

Κάθε αγώνας χρειάζεται ένα API request. Το workflow έχει προεπιλογή 85
requests ώστε να παραμένει κάτω από το ημερήσιο όριο των 100.

Η βάση έχει 716 κατάλληλους ολοκληρωμένους αγώνες στις σεζόν 2022–2024.
Άρα η πρώτη συλλογή χρειάζεται περίπου 9 ημερήσιες εκτελέσεις.

Κάθε εκτέλεση κάνει commit τα νέα δεδομένα. Στην επόμενη εκτέλεση
παραλείπονται όλοι οι αγώνες που έχουν ήδη ελεγχθεί.

Αγώνας για τον οποίο το API απάντησε αλλά δεν είχε πλήρη Corner Kicks και
Yellow Cards αποθηκεύεται ως `statistics_available: false`, ώστε να μην
καταναλώνει το ίδιο request ξανά και ξανά.
