# Αυτόματα κόρνερ και κάρτες

Το workflow `.github/workflows/collect-match-statistics.yml` ονομάζεται **Sync free match history**.

Τρέχει καθημερινά και:

1. κατεβάζει τα διαθέσιμα Greece CSV του Football-Data.co.uk,
2. βρίσκει ολοκληρωμένους αγώνες,
3. αντιστοιχίζει κάθε αγώνα με την υπάρχουσα SQLite βάση,
4. διαβάζει `HC/AC` για κόρνερ και `HY/AY` για κίτρινες κάρτες,
5. αποθηκεύει μόνο πλήρεις εγγραφές,
6. κάνει commit τη βάση και το dataset,
7. ενεργοποιεί μετά την αναδημοσίευση του feed.

Δεν χρησιμοποιεί το site της Super League και δεν χρειάζεται API key.

Τα νέα δεδομένα μπαίνουν στον αλγόριθμο στο αμέσως επόμενο run, με την προϋπόθεση ότι η δωρεάν πηγή έχει ήδη δημοσιεύσει το ενημερωμένο CSV.
