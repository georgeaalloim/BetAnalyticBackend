# BetAnalytic — πλήρως αυτόματα κόρνερ και κάρτες

## Τι κάνει πλέον το κύριο GitHub Action

Κάθε δύο ώρες εκτελείται το `.github/workflows/update-betanalytic.yml` και:

1. κατεβάζει πρόγραμμα και αποτελέσματα από το Fixtur.es,
2. εντοπίζει αυτόματα την πιο πρόσφατη σεζόν της βάσης,
3. κατεβάζει τα CSV της ελληνικής Super League για τις τέσσερις πιο πρόσφατες σεζόν από το Football-Data.co.uk,
4. ταυτίζει τους αγώνες με τα ήδη υπάρχοντα fixture IDs,
5. συμπληρώνει γκολ, κόρνερ, κίτρινες/κόκκινες κάρτες, σουτ, σουτ στην εστία, φάουλ και οφσάιντ,
6. ενώνει αυτά τα δεδομένα με όσα είχαν ήδη συλλεχθεί από API-Football,
7. επανεκπαιδεύει τα μοντέλα μόνο με αγώνες πριν από την ώρα υπολογισμού,
8. παράγει νέο `feed.json` και το δημοσιεύει στο GitHub Pages.

Δεν απαιτείται καθημερινό πάτημα κουμπιού και δεν χρησιμοποιείται χειροκίνητο schedule override.

## Γιατί δεν γίνεται scraping του slgr.gr

Οι επίσημοι Όροι Χρήσης της Super League απαγορεύουν την αυτοματοποιημένη άντληση δεδομένων χωρίς άδεια. Για αυτό το backend δεν κάνει scraping του επίσημου site. Αν δοθεί γραπτή άδεια ή δημόσιο επίσημο API, μπορεί να προστεθεί ως πηγή προτεραιότητας χωρίς αλλαγή των μοντέλων.

## Πηγές

- Πρόγραμμα/αποτελέσματα: `Fixtur.es calendar feed`
- Αναλυτικά ιστορικά και νέα στατιστικά: `Football-Data.co.uk` CSV (`G1.csv`)
- Προϋπάρχον seed και προαιρετικός έλεγχος: `API-Football`

Το Football-Data URL κατασκευάζεται αυτόματα:

- σεζόν 2025-26 → `https://www.football-data.co.uk/mmz4281/2526/G1.csv`
- σεζόν 2026-27 → `https://www.football-data.co.uk/mmz4281/2627/G1.csv`

Αν το CSV της νέας σεζόν δεν έχει δημοσιευτεί ακόμη, το workflow συνεχίζει με τα ήδη διαθέσιμα δεδομένα και το ξαναελέγχει αυτόματα στο επόμενο run.

## Δυναμικές γραμμές

### Γκολ

Παραμένει η δυναμική επιλογή από τις γραμμές 0.5 έως 5.5.

### Κόρνερ

Εξετάζονται οι γραμμές 5.5 έως 13.5. Εμφανίζεται η πιθανότερη πλευρά μόνο μεταξύ γραμμών κοντά στην αναμενόμενη συνολική τιμή.

Παράδειγμα:

```json
"corners_market": {
  "status": "ready",
  "expected": {"home": 5.4, "away": 4.1, "total": 9.5},
  "selected": {
    "label": "Over 8.5",
    "probability_percent": 62.7
  }
}
```

### Κίτρινες κάρτες

Εξετάζονται οι γραμμές 1.5 έως 7.5 και εφαρμόζεται ο ίδιος κανόνας σχετικών γραμμών.

## Μοντέλο κόρνερ/καρτών

Το `Bayesian-Smoothed Count Markets v0.1` χρησιμοποιεί:

- μέσο όρο πρωταθλήματος εντός/εκτός,
- επιθετική συμπεριφορά της γηπεδούχου εντός,
- αμυντική συμπεριφορά της φιλοξενούμενης εκτός,
- αντίστοιχη εκτίμηση για τη φιλοξενούμενη,
- Bayesian smoothing πέντε αγώνων,
- Poisson κατανομή για τις πιθανότητες Over/Under.

Απαιτούνται τουλάχιστον 60 πλήρεις αγώνες πρωταθλήματος και τουλάχιστον τέσσερις σχετικοί εντός/εκτός αγώνες ανά ομάδα. Διαφορετικά η συγκεκριμένη αγορά επιστρέφει `unavailable` αντί για αυθαίρετη πρόβλεψη.

## Προστασία από temporal leakage

Για αγώνα με ώρα έναρξης `T`, χρησιμοποιούνται αποκλειστικά εγγραφές με:

```text
fixture_date < T
```

Το feed περιλαμβάνει strict walk-forward validation για κόρνερ και κάρτες, όπου κάθε ιστορική πρόβλεψη υπολογίζεται μόνο από προγενέστερα παιχνίδια.

## Νέα πεδία στο feed

Μέσα στο `prediction`:

```text
corners_market
yellow_cards_market
```

Στο fixture:

```text
kickoff_time_confirmed
schedule_source
training_statistics_used
latest_training_statistics_date
```

Η παλιά Android εφαρμογή αγνοεί τα πρόσθετα πεδία και συνεχίζει να λειτουργεί. Για να εμφανιστούν κόρνερ και κάρτες χρειάζεται επόμενο Android patch.
