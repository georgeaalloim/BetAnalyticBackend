# Διόρθωση ρυθμού αιτημάτων για κόρνερ και κάρτες

Το δωρεάν API-Football επιτρέπει 100 requests ημερησίως αλλά μόνο 10 ανά λεπτό.
Ο collector πλέον αφήνει από προεπιλογή 8 δευτερόλεπτα ανάμεσα στην έναρξη δύο requests.

Προτεινόμενη χειροκίνητη εκτέλεση:

- seasons: `2022,2023,2024`
- max_requests: `85`
- request_delay_seconds: `8`

Τα δεδομένα που έχουν ήδη αποθηκευτεί δεν ξαναζητούνται.
